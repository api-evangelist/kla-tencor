# KLA (kla-tencor)

KLA Corporation (formerly KLA-Tencor) is a leader in process control and process-enabling solutions for manufacturing wafers and reticles, integrated circuits, packaging, printed circuit boards and flat panel displays. KLA delivers advanced inspection tools, metrology systems, and computational analytics for the semiconductor industry. Keep Looking Ahead.

KLA does not publish a public developer portal or open API program; customer-facing software and tool APIs are provided to KLA customers under contract and are not publicly available.
